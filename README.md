# Curio

**Discover. Connect. Belong.**

Curio is a real-time community platform built around conversations and shared interests.

The long-term vision is to create a space where people can discover communities, participate in discussions, share useful information, and connect with others through public and private rooms.

Curio is currently in its early development stage.

## Current Features

- User registration and login
- Secure password hashing
- Real-time messaging using WebSockets
- Live online-user tracking
- Multi-tab session handling
- Responsive chat interface

## Tech Stack

- **Backend:** Python, Flask
- **Real-time communication:** Flask-SocketIO
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Templating:** Jinja2
- **Authentication:** Flask sessions and Werkzeug password hashing

## Project Direction

Curio is evolving from a simple real-time chat application into a broader community platform.

Planned features include:

- Multiple public and private chat rooms
- Persistent message history
- Community discovery
- Direct messaging
- User profiles
- Improved security and scalability

These features are planned and are not necessarily implemented yet.

## Development Status

<code>Early Development — Active</code>

The current version is a single-room real-time chat prototype. It serves as the foundation for the larger platform.
